# tech-news-aggregator frontend

React + TypeScript + Vite + Tailwind CSS。

## セットアップ

```bash
cd frontend
npm install
```

## 起動

```bash
npm run dev
```

開発サーバ: <http://localhost:5173>
（バックエンド `localhost:8000` に `/api` プロキシで接続）

## 主なスクリプト

```bash
npm run dev        # 開発サーバ
npm run build      # 本番ビルド
npm run typecheck  # 型チェック
npm run lint       # ESLint
npm run test       # Vitest
```
