# 指摘履歴

PlanReviewer / CodeReviewer がレビューで差し戻した指摘を記録する。
Planner / Implementer は計画・実装の前にこのファイルを参照し、過去の指摘を再発させないようにする。

## フォーマット

```
## YYYY-MM-DD — Sprint X

### 指摘者: PlanReviewer / CodeReviewer
- カテゴリ: 受け入れ条件 / あいまい表現 / エラーケース / 依存関係 / 整合性 / セキュリティ / パフォーマンス / 規約違反 / カバレッジ / 可読性
- 該当箇所: ファイル名やセクション
- 内容: なぜ問題か
- 解消方法（事後記録）: 修正後にどう直したか
```
